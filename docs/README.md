# docs/

Place your UI screenshot here as `ui_screenshot.png`.

**How to take it:**
1. Run `python app.py`
2. Open http://127.0.0.1:7860 in your browser
3. Upload a face image and run the analysis
4. Take a screenshot of the full browser window
5. Save it as `docs/ui_screenshot.png`

The README.md will automatically display it.
